# 태스크 보드

> 개인 태스크 단일 보드. report 와 달리 immutable 이 아니라 계속 편집한다.
> 라인 포맷: `- [ ] <할 일> · src:<출처> · @담당 · due:YYYY-MM-DD · note:한줄`
> `src:` 에 **어디서 흘러온 일인지** 남긴다(예: `src:#채널 2026-05-18`, `src:회의 2026-05-18`, `src:/eod`).
> 이 보드에는 **개인 할 일**(늦어져도 나만 불편한 일)을 둔다. 공유 할 일은 GitHub issue 가 원본이다(`tools/company-wiki.py task-new`, CLAUDE.md §17.3).
> 보드의 줄을 GitHub 으로 옮기면 그 줄 끝에 `· gh:<owner/repo#n>` 을 붙인다. 이 표시가 붙은 줄은 상태의 원본이 GitHub 이므로 체크박스를 따로 바꾸지 않는다.
> 나에게 배정된 GitHub 이슈는 여기에 옮겨 적지 않는다. `/morning` 이 `task-list --mine` 으로 읽어 하루 계획에 넣는다.
