`/log` — **내가 뭘 했는지 묻지 않는다. 세션에서 직접 읽어 쓴다.** 마지막 기록 이후 모든 레포(`~/.claude/projects/**`)의 Claude Code 세션을 훑어 오늘 한 일을 `raw/reports/daily/<오늘>.md` 에 적재한다. `/eod` 가 마감 때 합성·지식화한다.

> **사실/한 일은 `/log`, 생각/배운점은 `/brain`.**
> 핵심 가치: **놓치는 것 없이.** 어느 워크스페이스에서 일했든 한 곳에 모인다.
> *(Claude Code 를 쓰는 사람만 자동 모드가 의미 있다. 안 쓰면 C 수동 캡처만 써도 된다.)*

입력: **$ARGUMENTS**

## 모드 판정 (먼저)

| $ARGUMENTS | 모드 |
|---|---|
| 비어 있음 / `--since-hours N` / `--since <ISO>` | **A. 세션 자동 캡처** (기본) |
| `done <항목>` | **B. 완료 체크** |
| 그 외 텍스트 | **C. 수동 한 줄 캡처** |

A 와 B·C 는 함께 올 수 있다 — 순서대로 처리한다.

---

## A. 세션 자동 캡처 (기본 모드)

### A-1. digest 뽑기

```bash
python tools/session-digest.py --since-file .log-cursor --exclude-session <현재 session-id>
```

- **커서 기준이지 시간 창이 아니다.** 6시간 만에 돌려도 6시간분을 전부 훑는다 — 시간 제약 없이 누락분을 따라잡는 게 이 커맨드의 설계다.
- `.log-cursor` 가 없으면(첫 실행) `--since-hours 12` 로 시작한다.
- `--since-hours N`·`--since <ISO>` 가 인자로 오면 그걸 우선한다(과거 소급 캡처용).
- **현재 세션은 제외**한다 — 지금 이 대화가 로그에 반사되면 잡음이다.
- digest 는 사용자 발화 + 편집 파일 + 실행 명령 + 커밋만 남긴 압축본(24시간 ≈ 10KB). 원본 transcript 는 절대 통째로 읽지 않는다.

### A-2. 합성 — 나열이 아니라 요약

digest 를 읽고 **레포/주제 단위로 묶어** 한 줄씩 만든다. 기계적 복사 금지:

- **묶는다**: 같은 세션의 20개 명령 → "무엇을 왜 했는지" 한 줄. 파일명 나열이 아니라 **작업 단위**로.
- **버린다**: 탐색·확인·실패 후 재시도·`/log` 자신의 실행. 결과가 남지 않은 시행착오는 안 적는다.
- **살린다**: 완료된 작업, 커밋, 굳은 결정, 막힌 지점, 새로 알게 된 사실.
- 레포가 여럿이면 **레포명을 접두**로: `sensor-firmware: BLE advertising 주기 30초→1분 조정`.
- 각 줄은 **한 문장**. 6개월 뒤의 내가 읽고 알아볼 만큼만 구체적으로.

### A-3. 배치

오늘 리포트(`raw/reports/daily/YYYY-MM-DD.md`)에 섹션별로 넣는다. 없으면 `/morning` 1단계 골격을 만들고 "아침 자리 없어 생성함" 한 줄 고지.

| digest 신호 | 목적지 |
|---|---|
| 완료한 작업·커밋 | `## 한 일` |
| 새로 안 사실·실험 결과 | `## 발견` |
| 굳은 결정 | `## 결정` |
| 막힌 것·실패·blocker | `## 막힘` |
| `## 오늘 할 일` 과 매칭되는 완료 | 해당 `- [ ]` → `- [x]` |

- **중복 방지**: 이미 그 섹션에 있는 내용이면 다시 적지 않는다. 같은 작업이 이어졌으면 기존 줄을 **보강**한다(새 줄 추가 아님).
- **마스킹**(§9): raw 도 커밋된다(§4.3). 고객·개인 식별 정보, 계정·토큰, 급여·계약액은 여기서 제거한다. 세션에는 마스킹 안 된 값이 그대로 있으므로 **반드시 거른다**.
- 기록 후 커서 갱신: digest 명령에 `--write-cursor .log-cursor` 를 붙이거나 별도 실행.

### A-4. 신호 감지 (있을 때만, 남발 금지)

- **brain 거리**(§16): 세션에서 본인의 판단·가설·반론이 드러났으면 한 줄 제안 — "이거 brain note 로 남길까요?"
- **태스크 거리**(§15): "나중에", "해야겠다" 하고 안 올라간 액션이 보이면 보드 반영 제안.
- 각각 **1~2개 상한**. 없으면 아무 말도 안 한다.

### A-5. 무인 실행 (선택)

매 시간 자동으로 돌리려면 `tools/hourly-log.ps1` 을 작업 스케줄러에 건다:

```bash
powershell -File tools/install-hourly-log.ps1          # 등록 (매 정각)
powershell -File tools/install-hourly-log.ps1 -Status  # 상태·최근 실행
powershell -File tools/install-hourly-log.ps1 -Remove  # 해제
```

- 결정적인 부분(digest 추출)은 스크립트가, 판단(합성·배치)만 headless Claude 가 한다.
- **활동이 없는 시간엔 LLM 을 호출하지 않는다** — 밤·주말에 돌아도 비용이 안 든다.
- 저녁에 `/eod` 를 돌리면 이미 쌓인 로그를 재료로 회고가 시작된다.

---

## B. 완료 체크

`## 오늘 할 일` 의 매칭되는 `- [ ] <항목>` → `- [x] <항목>`. 부분 텍스트만 줘도 가장 가까운 항목 1개에 적용, 애매하면 후보를 보여주고 멈춘다.

## C. 수동 한 줄 캡처

`## 한 일` 끝에 `- <내용>` 추가. 명백히 문제·blocker 면 `## 막힘`, 새로 안 사실이면 `## 발견`. 애매하면 `## 한 일`. 입력 원문 톤을 살리되 평어체.

---

## 마무리

- 한 줄로만 보고: `세션 N개/레포 M개 → 한 일 K줄 · 발견 J · 막힘 I` 또는 `기록함: <무엇>`.
- **자동 실행(스케줄러)일 때는 조용히**: 새로 적을 게 없으면 파일도 안 건드리고 "변화 없음"만.

## 안전·톤
- **오늘 파일만** 수정. 지난 날짜 파일은 immutable(§4.3) — 절대 건드리지 않는다.
- `~/.claude/projects/` 와 `raw/sessions/` 는 **읽기 전용**(§4.3 예외 3).
- 사용자와의 확인은 **존댓말**, 리포트 본문은 **평어체**(§3).
- 빠른 캡처 도구 — 깊은 합성·지식화는 하지 않는다(그건 `/eod`·`/brain` 몫).
- 전사 wiki 는 건드리지 않는다(§17 승격은 `/eod`·`/promote` 소관).
